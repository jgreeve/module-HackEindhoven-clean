# tablette

A natural language generative meta-application platform.

This is the shared host inside the HackEindhoven npm workspace. Install and run
from the [repository root](../../README.md). New features belong in
`packages/module-*`; see [the module guide](../../docs/module-development.md).

Full documentation is at [docs.tablette.bimr.net](https://docs.tablette.bimr.net).
